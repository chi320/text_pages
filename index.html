GitHub Pages 是什麼？

GitHub Pages 是 GitHub 提供的靜態網站託管服務，可以直接把儲存庫內容部署成網站， 非常適合做個人履歷、專案文件、活動頁面或教學內容。

主要特色

免費託管

公開儲存庫可免費使用，快速把內容上線。

版本控制整合

透過 Git 管理網站內容，每次更新都有紀錄。

自動部署

推送到指定分支後，GitHub 會自動重新發布網站。

快速建立步驟

  1. 在儲存庫根目錄建立 index.html。
  2. 前往儲存庫 Settings → Pages。
  3. 選擇部署來源（例如 main 分支根目錄）。
  4. 儲存後等待數十秒，取得網站網址並開啟確認。

常見用途

  • 專案說明文件（Docs）
  • 作品集或履歷頁
  • 簡單產品 Landing Page
  • 課程與教學筆記展示
